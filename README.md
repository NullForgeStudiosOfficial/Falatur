# Falatur

A foam combat ruleset focused on honor, safety, and craftsmanship.

## Latest Version

📖 **[Download the latest rulebook (PDF)](Falatur.pdf)**

---

Falatur is a foam combat system inspired by decades of established foam combat while introducing a new combat model centered around realistic weapon roles, player honor, and straightforward construction standards.

The PDF above is always the current official release.
